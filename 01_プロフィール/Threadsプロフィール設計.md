## ✅ 実際の設定（2026-09時点・稼働中）

**アカウント名**: `にこ｜元教室長ゆる知育` → **`にこ｜元幼児教室長のゆる知育` を推奨**
- 変遷: 「にこ｜ワーママのためのゆる知育」→「にこ｜元教室長ゆる知育」→（推奨）「にこ｜元幼児教室長のゆる知育」
- ※**リプ周り戦略ではリプ欄に名前しか表示されない**ため、名乗れない肩書き（元教室長）を入れるのが有利
- ※「知育教室」より**「幼児教室」のほうが具体的で伝わる**（七田式・ベビーパーク等、実在のカテゴリとして認識されている）

| 案 | 長さ | 特徴 |
| --- | --- | --- |
| **にこ｜元幼児教室長のゆる知育** | 14字 | **権威＋発信内容の両取り。推奨**（「幼児教室」で足が止まり「ゆる知育」で何の発信かわかる＝フォロー判断が1秒） |
| にこ｜幼児教室の元教室長 | 12字 | 権威は最強だが発信テーマが消える |
| にこ｜元教室長ゆる知育 | 11字 | 短いが「何の教室長？」が伝わりにくい |

**プロフィール文**:
```
＼時間がないワーママでも1日15分でできる知育／
子供が自分で考えて動く子になる
📖 0〜3歳の声かけ・おうち知育を発信
🧠 日常生活の中でゆるっとできる関わり方
🐣 知育教室の元教室長 | 週7ワンオペワーママ
Amazonアソシエイト参加中
```
- 良い点: 便益（1日15分）＋未来（自分で考えて動く子）＋権威＋親近感＋アソシエイト表記（規約OK）
- **修正版**: `🐣 幼児教室の元教室長（面談300件）| 週7ワンオペワーママ`
  - 「知育教室」→「**幼児教室**」（具体的で伝わる）
  - 「面談300件」で規模感を追加

**固定投稿**: ⚠️ **要変更**（現在はおともだちえほんのアフィリ投稿）
- 固定はリプ周りで来た初対面の人が最初に読む場所。商品紹介だと第一印象が「物を売る人」になる
- フォロワー22人の段階で信頼構築の前に販売が来ている＝順序が逆
- 「らしいです」の伝聞は、初対面には弱い効果報告に見える
- → 絵本投稿は通常投稿として流す（内容は良いので回せる）

**差し替え用の固定投稿原稿**:
> 元幼児教室の教室長ですが、娘を教室に通わせていません。
>
> 教室長として、保護者面談を300件、講師100人に声かけを教えてきました。
> 月謝を払って通ってくれる家庭に、毎日「通う価値」を伝える仕事でした。
>
> でも現場で見ていて、伸びる子の差は「どの教室に通っているか」じゃなかったんです。
> 家での声かけと、関わり方でした。
>
> だから娘には、教室に通わせずにやってみています。
> 週7ワンオペなので、できるのは1日15分くらいですけど。
>
> ここでは、その中でやってることを書いていきます🫶

→ 3秒で「何者か」「なぜフォローする価値があるか」が伝わる。数字（300件・100人）＋意外性（教室長なのに通わせない）＋親近感（週7ワンオペ・15分）

## 前提（決定済み事項）

- **ジャンル**: 元教室長ママの「家庭でできる幼児教育」
- **収益化**: 教材販売（note / Tips / Brain）＋アフィリエイト
- **一行コンセプト**:
> 何百組の親子を見てきた元教室長ママが、「知育、何すればいいの？」と迷う0〜3歳ママへ、家庭でできる声かけ・関わり方を届け、"教室に通わせなくてもうちの子は大丈夫"と自信を持てるようになるアカウント。

### コンセプト要素分解

| 要素 | 内容 |
| --- | --- |
| 誰が（キャラ設定） | 元幼児教室の教室長・バイリンガル保育園立ち上げ経験×2歳児ママ。プロなのに偉ぶらず本音を言う等身大キャラ。根拠を添えて語れる論理派の一面も |
| 誰に（ペルソナ） | 知育に興味はあるけど、何から始めればいいかわからない0〜3歳ママ。SNSで知育情報を見ては焦りだけが募っている |
| 何を軸に（テーマ） | 家庭でできる「声かけ・関わり方・距離感」の知育。週1〜2回、塾なし国立附属受験の挑戦記録を挟む |
| どんな価値・未来 | 「教室に通わせなくても、私の関わり方で大丈夫」という自信。今日から真似できる声かけが増えていく |

### 設計方針

- 顔出し: **なし**
- 世界観: **やさしいナチュラル系**（くすみカラー・絵文字は控えめ）
- NG要素: 煽り・不安をあおる表現／意識高い系・キラキラママ感／子どもの個人情報・顔出し

## 1. アイコン

**方向性: くすみカラーの手描き風イラスト**

- 色: ベージュ×くすみグリーン or くすみピンク。背景は淡い単色（白背景・黒背景どちらでも浮かない）
- モチーフ: ママと子どもの後ろ姿、または「しゃがんで子どもと目線を合わせている大人」
  - テーマ「関わり方・距離感」をアイコン自体で体現する
  - 本・えんぴつなど"お勉強感"のあるモチーフはNG（教室いらずのコンセプトと矛盾）
- タッチ: 線の細いゆるい手描き風。きっちりした線や原色は「先生感」が出すぎるので避ける
- 作り方: Canvaのイラスト素材＋淡色背景で自作 → こだわるならAI生成 or ココナラで3,000〜5,000円

## 2-2. アカウント名の再設計（2026-08追記・便益型への変更提案）

### 伸びているアカウント名の共通点（実例: イケメンの育て方／プリンセス育児／優しい天才の育て方／ゆる脳育児／子供が一生勉強に困らない土台作り／免疫ゴリラ🦍鼻垂れ小僧のトリセツ／学びのしかけ屋／イケメン研究所）
1. **肩書きではなく「手に入る未来」が名前**（結果を名乗る。肩書き型は一つもない）
2. **個人名が入っていない**（コンセプト自体が名前＝ブランド化しやすい）
3. **親の願望を上品にまとめず直球で言う**（非認知能力→天才・イケメン）
4. **役割名・場所名で専門家感**（しかけ屋／研究所／トリセツ）
5. **短い**（ゆる脳育児＝5文字）
6. **意外性でキャラ立ち**（免疫ゴリラ）

### 当アカウントの便益型・名前案
| 案 | 評価 |
| --- | --- |
| **教室いらずの育て方** ★推奨 | 元教室長が言うから成立する＝他人が名乗れない。理念がそのまま名前になり、逆張りで目を引く |
| **ひとりでできる子の育て方** | 便益が直球。娘の実例（着替え・トイレ・体洗い）と一致。煽らずに欲しい未来を提示 |
| **勝手に育つ子のつくり方** | ママのラクさが匂う。「やりすぎない育児」の便益版でキャッチー |
| やりすぎない育児 | 世界観は最高だが便益が伝わらない → **サブコピー向き** |

### 実務的な形
> **教室いらずの育て方｜元幼児教室の教室長**
（名前で便益、サブで権威の両取り）

### 注意
「イケメン」「天才」系は**比較と願望を煽る名前**。読者定義（他の子と比べて焦っているママ）と矛盾するため採用しない。「教室いらず」「ひとりでできる子」なら煽らずに便益を出せる。

## 4. なぜこのプロフィールが刺さるのか

### フォロー率が上がる理由

- Threadsは「投稿がバズる→プロフィールに飛ぶ→3秒で判断」でフォローが決まる
- 案1は最初の15文字「元幼児教室の教室長→2歳ママ」で肩書きの逆転が完結し、「何百組」で信頼、「大丈夫」で未来、「挑戦中」で続きを見たい理由、と3秒に4要素が入っている

### コンセプトとの整合性

- あおり表現ゼロ・「〜すべき」ゼロで「大丈夫と思ってもらう」価値と矛盾しない
- 絵文字は🌿1つだけ。ナチュラル系は「絵文字を盛らない」ことで表現する
- 子どもは「2歳ママ」表記のみ。受験発信でも「娘・息子」を避け「わが子」で通す

### 運用のコツ

1. **固定投稿に挑戦の宣言を置く**: 「なぜ元教室長なのに、教室に通わせないのか」を固定投稿で語る（フォローの最後のひと押し）
2. **数字は育ったら差し替える**: フォロワー1,000人・教材販売開始などの実績が出たらプロフィールを更新する
3. **リンク欄は今は空でOK**: 教材完成のタイミングでnote/Tipsへの導線を置く
